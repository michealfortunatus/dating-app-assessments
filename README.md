# Dating App Assessment

## Overview

Matchly - A minimalistic Tinder-style dating application built with React Native Expo.

## Features

* Welcome Screen
* Swipe Discover Screen
* Match Details Screen
* Smooth Swipe Gestures
* Responsive Design

## Tech Stack

* React Native Expo
* TypeScript
* React Navigation
* React Native Deck Swiper

## Installation & Running Locally

### Prerequisites

* Node.js (v18+ recommended)
* npm
* Expo Go app (optional for testing on a physical device)

### Setup

```bash
npm install
```

### Start Development Server

```bash
npm start
```

Then:

* Press `a` to launch on an Android Emulator.
* Press `i` to launch on an iOS Simulator (macOS only).
* Scan the QR code with the Expo Go app to run on a physical device.

## APK Installation

A prebuilt APK is available in the Google Drive folder below:

**Google Drive:**
https://drive.google.com/drive/folders/1P5MisB2JzQSxZCUybHRR8tPTxAqj0UOY?usp=sharing

### Install on Android

1. Open the Google Drive link above.
2. Navigate to the **Dating App** folder.
3. Download the APK file to your Android device.
4. If prompted, enable **Install from Unknown Sources** or **Allow from this source** in your device settings.
5. Open the downloaded APK file.
6. Tap **Install**.
7. Once installation is complete, open the app from your device's app drawer.
